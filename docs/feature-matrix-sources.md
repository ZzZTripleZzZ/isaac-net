# Feature matrix sources

This page backs the feature matrix in [configurability.md](configurability.md#feature-matrix). Each line gives one (tool, feature) cell: the status we recorded, the feature name as the tool's own documentation writes it, and the page and section where it is stated. A cell that no official page confirms is marked *unverified*, and a cell confirmed only by the source code says so.
